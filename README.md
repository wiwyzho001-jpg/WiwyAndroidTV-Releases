# WiwyAndroidTV · APKs

Este repositorio publica únicamente los APK firmados de WiwyAndroidTV para que la app pueda comprobar y recibir actualizaciones OTA. El código fuente se mantiene en el repositorio privado [WiwyAndroidTV](https://github.com/wiwyzho001-jpg/WiwyAndroidTV).

Descarga la versión actual desde [Releases](https://github.com/wiwyzho001-jpg/WiwyAndroidTV-Releases/releases/latest). Android mostrará su confirmación normal al instalar una actualización.
